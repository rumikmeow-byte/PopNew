# GiftsEzz — Telegram Mini App (Prototype)

Фиолетовый клон интерфейса в стиле Gorilla Case / gift-case приложений.

## Что есть

- Главный экран с играми (Бесплатно, Кейсы, Апгрейд, Краш, Контракты, Мины, Яйца, PvP, Слоты)
- LIVE-лента подарков
- Пополнение баланса (Звёзды / GRAM / Подарки)
- Профиль + реферальная система
- Нижняя навигация
- Тёмно-фиолетовая тема
- Поддержка Telegram WebApp API

## Как открыть

Просто открой `index.html` в браузере (лучше в мобильном режиме DevTools).

Или залей папку на любой хостинг (GitHub Pages, Vercel, Netlify и т.д.) и подключи к боту как Web App.

## Как превратить в настоящий бот

1. Создай бота через @BotFather
2. Включи Mini App / Web App
3. Укажи URL на задеплоенный `index.html`
4. Добавь бэкенд (Node.js / Python) для:
   - Авторизации через `initData`
   - Баланса и инвентаря
   - Открытия кейсов
   - Апгрейда
   - Выплат и т.д.
