Как работает BATTLES

1. Игроки добавляют ставки в общий банк.

2. После 2 игроков сервер запускает раунд.

3. Шанс каждого игрока = его ставка / общий банк.

4. Победитель определяется серверным seed и получает банк.

5. После завершения seed раскрывается для проверки результата.

Как работает CRASH

Коэффициент растёт в реальном времени. Пока раунд активен, можно забрать ставку по текущему x. Если раунд взорвался раньше — активная ставка сгорает. Для каждого раунда сервер заранее фиксирует hash seed.
